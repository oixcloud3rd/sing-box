# 域名评估器

### 结构

```json
{
  "domain_evaluators": [
    {
      "tag": "dns-check",
      "server": "dns-server-tag"
    }
  ]
}
```

### 字段

#### tag

域名评估器的唯一标签。

#### server

用于评估域名的 DNS 服务器标签。

省略时由 DNS 规则选择服务器。

评估器首先执行静默的仅缓存查询。缓存未命中不会阻塞当前连接：本次连接使用原目标，同时在后台执行普通 DNS 查询；查询成功后，后续连接即可使用已评估的域名。

每个评估器拥有独立且有界的正、负缓存。负结果缓存 10 秒，同一域名的并发后台查询会被合并。
